## 3. 逐项做法

- **O1**：在 `cache.ts` 新增 `healthKey(url)` / `healthUrlFromKey(key)` 作为唯一 key 构造入口，固定使用 `canonicalUrl(url)`（不传 `ignoreWww`）。`scan.ts` 写入改调 `healthKey`，`useHealth.ts` 反解改调 `healthUrlFromKey`。`ignoreWww` 继续只用于重复判定（`duplicates.ts`），不再污染读取方无法还原的缓存键。
- **O2**：`Settings` 增 `version: number` 与 `SETTINGS_VERSION = 1`；`normalize` 前加 `migrate`：无 version 的旧数据补齐版本并保留字段，高于当前版本的数据回退默认避免旧代码误写。所有写操作统一走模块内串行队列 `writeSettings(transform)`，每次基于最新存储值合并后再写，消除同页面内 read-modify-write 交错。跨页面并发仍由 `storage.onChanged` 刷新内存，完整跨上下文互斥列入后续。
- **O3**：`Backend` 增 `isTabContext(): Promise<boolean>`；Chrome 实现用 `chrome.tabs.getCurrent()`，Demo 实现返回 `false`；`layout.ts` 只调 `getBackend()`，并加源码级断言防止回归。
- **O4**：Drawer 采用与 Modal 相同的 `onCloseRef` + `[open]` 依赖 + `event.stopPropagation()`，面板定位由全局 `querySelector` 改为 `useRef`。
- **O5**：`clickRow` 参数由 `React.MouseEvent` 收窄为 `shiftKey: boolean`；checkbox 用 `onChange` 统一处理鼠标与键盘合成事件，删除空 `onChange` 与重复 `onClick`。
- **O6**：README/技术方案同步「Enter 新标签页打开」与 popup 双形态尺寸；测试徽章数字按实测更新；CI 增加 `test:coverage` 与 `package`（版本一致性校验）。
