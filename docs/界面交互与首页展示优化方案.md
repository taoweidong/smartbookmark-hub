# SmartBookmark Hub 界面交互与首页展示优化方案

> 版本：v1.0 ｜ 日期：2026-11-10 ｜ 状态：待评审
> 配套实施计划：[界面交互与首页展示优化-实施计划.md](./界面交互与首页展示优化-实施计划.md)
> 基线：v2 质量轮（R0–R7）已完成，单测 515 例 / 38 文件、E2E 38 项全绿（2026-11-10 实测）。本轮只做**易用性增强**，不重复质量轮已修项；遗留清单中「完整焦点陷阱与 TabStrip 方向键导航」在本轮清偿。

---

## 1. 目标与非目标

### 1.1 目标

1. **首页内容优先**：首屏从「设置机器 + 统计仪表」转为「书签内容」，1280×800 下首张卡片顶边 ≤ 200px（现状 ≈ 390px），首屏可见 ≥ 3 行卡片。
2. **设置收纳**：常显设置条整体迁入「视图设置」抽屉，首页零设置控件（空态引导除外）。
3. **搜索即开即用**：搜索胶囊空查询聚焦时给出最近搜索 / 最近添加面板（命令_palette 惯例）。
4. **弹窗自适应**：popup 高度随内容伸缩，消除固定 560px 的死区与重复快捷键提示；同一份 `popup.html` 在「工具栏弹窗（宽 360）」与「标签页打开（铺满窗口宽）」两种形态下各自自适应。
5. **键盘贯穿**：TabStrip 方向键、弹层焦点陷阱、`Alt+1..8` 切页签、`?` 快捷键帮助。
6. **引导与响应式**：首跑推荐可感知、空态一键推荐、<1024px 文件夹导航不缺失。

### 1.2 非目标（YAGNI，沿用并扩展 v2 遗留清单）

- 卡片网格方向键导航、首页拖拽排序（Tab 已可达，收益不抵改动面）
- 云同步 / AI 标签 / 新闻、天气等资讯 widget（违反本地优先或属噪声）
- options 管理台大重构（完成度高，本轮不动）
- CSP 收紧、core 静态 import 动态化、demo 跨页面同步（沿用 v2 遗留清单）

## 4. 独立选型评估

### 4.1 设置入口形态（决策 D1）

| 方案 | 描述 | 取舍 | 结论 |
|---|---|---|---|
| **A 齿轮抽屉（推荐）** | 命令栏右侧 `SlidersHorizontal` 按钮开右侧 Drawer，DisplayControls 控件原样迁入分组 | 复用既有 `Drawer`/`popupStack`；零新增模式状态；控件迁移成本低；小屏 `max-w-92vw` 已兜底 | **采纳** |
| B 编辑模式（nightTab 式） | 全局 view/edit 状态，编辑模式才显示分区管理控件与拖拽 | 需新增模式状态 + 每分区编辑 UI + 模式切换入口；改动面大，且我们的控件是「视图偏好」而非「内容编辑」，语义不符 | 备选不采纳 |
| C 维持常显条 | 不动 | 不解决 U1/U2 | 否决 |

### 4.2 统计形态（决策 D2）

| 方案 | 描述 | 取舍 | 结论 |
|---|---|---|---|
| **A 行内迷你统计（推荐）** | 问候行内联 `总数 N · 近 7 天 +N · 健康 N%`，等宽数字；`showStats` 继续控制其显隐（默认 true 不变） | 首屏成本 ≈0（与问候同行）；信息不丢；无设置迁移 | **采纳** |
| B 四卡保留但默认折叠 | `showStats` 默认改 false | 老用户已存 true 不受益；展开仍占 92px；默认值变更属行为变更 | 否决 |
| C 删除统计 | 移除 | 丢失健康度入口（治理能力的首页锚点） | 否决 |

四张 `StatTile` 卡片随之退役；若确认无其他消费方则删除组件（实施期 grep 确认）。

### 4.3 popup 高度（决策 D3）

| 方案 | 描述 | 取舍 | 结论 |
|---|---|---|---|
| **A 内容驱动（推荐）** | `body { width:360px; height:auto; max-height:600px }`，根容器 flex + `max-height` 约束，中部 `min-h-0 overflow-y-auto` | Chrome popup 按内容自适应（上限 600）；死区消失；结果多时中部滚动 | **采纳** |
| B 维持固定 560 | 不动 | 死区与占位文案仍在 | 否决 |

配套：删除 popup 页脚重复提示（保留结果面板内一份）；删除「结果已在上方展开」占位分支——body 恒显快捷动作 + 最近搜索 + 最近添加，结果下拉覆盖其上。

形态判定：`popup.html` 有两种打开方式——扩展工具栏弹窗与直接以标签页打开。Chrome 弹窗的初始视口宽度就是上限 800px，用视口宽度媒体查询区分会把弹窗撑成 800px；唯一可靠判据是 `chrome.tabs.getCurrent()`——只有当前文档位于标签页时它才有值。据此写 `data-sbh-layout="popup|tab"`：弹窗形态宽 360px、高度内容自适应（上限 600px）；标签页形态铺满窗口宽度，内容列上限 900px 居中，快捷动作 4 列、最近列表 2/3 列排布。

打开行为：`Disposition` 只保留 `'newTab' | 'newWindow'`，`'current'` 从类型层面删除——书签卡片、搜索结果、omnibox 一律开新标签页，管理台入口也改用 `chrome.tabs.create(options.html)`，避免复用已有标签页把用户的面板刷新掉。

## 5. 主方案设计

### 5.1 首页首屏重构（U1/U2/U3）

**Before（1280×800 实测）**

```
┌ 命令栏  品牌 | 搜索胶囊 | 主题 管理台 ┐  ≈56px
┌ 页签条  常用3 ✎ │ +                  ┐  ≈48px
┌ 设置条  布局 卡片 排序 每组 背景 主色 统计 │ 选文件夹 重置 ┐ ≈48px
┌ 问候 + 日期                    仅存本机 chip ┐  ≈48px
┌ 统计四卡 ┐                                        ≈92px
┌ rail │ 分区头 + 卡片第一行 ┐                        首卡 y≈390px
```

**After**

```
┌ 命令栏  品牌 | 搜索胶囊 | 主题 ⚙视图 管理台 ┐  ≈48px
┌ 页签条  常用3 ✎ │ +                       ┐  ≈36px
┌ 问候 日期 · 总数 128 · 近7天 +6 · 健康 92% ┐  ≈40px
┌ rail │ 分区头 + 卡片 ┐                       首卡 y≤200px，首屏 ≥3 行
```

- header 收敛为两层；`DisplayControls` 从 header 移除（§5.2）。
- 问候区单行化；「数据仅存本机」chip 移至页脚（与隐私文案同处，语义归位）。
- 首跑推荐 hint chip 条件性出现在问候行（§5.7），不常驻。
- 入场阶梯动画、`prefers-reduced-motion` 约定保持不变。

### 5.2 视图设置抽屉（U2）

入口：命令栏右侧 `SlidersHorizontal` 图标按钮（`aria-label="视图设置"`，title 同），位于 ThemeToggle 与管理台之间。复用 `Drawer`（400px、Esc/遮罩关闭、弹层栈已接入）。

控件迁移映射（行为与写盘语义不变，含防抖滑杆/取色器）：

| 现控件 | 抽屉分组 |
|---|---|
| 布局 grid/list、卡片 S/M/L、排序 select、每组滑杆 | 布局与卡片 |
| 背景 select + 取色器 + 换图按钮、主色四圆点 | 背景与主色 |
| 统计开关 | 显示（控制行内统计） |
| 选择文件夹（primary） | 文件夹（分组顶部主按钮） |
| 重置视图 | 抽屉 footer |

迁移提示：升级后首次打开首页一次性 Toast「显示设置已移入右上角『视图设置』」。触发条件：init 时** seeding 前**读到的旧存档 `dashboard.seeded === true`（即升级用户，新装用户不提示）且 `!controlsMovedSeen`；提示后写 `controlsMovedSeen: true`（§6）。

### 5.3 问候与行内统计（U3）

单行：`问候语 + 日期·周几`（保留现有字号对比）→ 分隔点 → 行内统计三段（等宽、语义色沿用：健康 ≥90% ok / 否则 warn / 未检测 faint）→ 行尾保留页签覆盖说明文案（clamp-1，窄屏隐藏）。`showStats=false` 时隐藏统计三段。统计计算逻辑（`App.tsx:75-88`）不变，仅渲染形态变化。

### 5.4 搜索零查询面板（U4）

- `useSearch`：`focus()` 无条件 `setOpen(true)`；导出 `open` 不再与 query 相与；`change('')` 保持面板开（清空输入即回到零查询面板），`clear()`（X 按钮）关闭。
- `SearchBox` 下拉内容三分支：有查询 → 现状结果/检索中/无匹配；**零查询 → 最近搜索 chips（≤6）+ 最近添加（≤6 行：favicon + 标题 + timeAgo，复用 popup 的行 markup 与 `result-row` 样式）+ 底部提示「Enter 搜索 · Ctrl+Enter 新标签页」**。
- 键盘语义：↑↓/Enter 仅作用于结果列表；零查询面板内元素为普通可 Tab 按钮——**空查询时 Tab 不关面板**（允许 Tab 进入 chips/最近添加行），有查询时 Tab 关面板（现状保留）；Esc 先关面板（现状层级保留）。
- 三入口共用：newtab/popup 自动受益；options 的全局搜索按钮跳转 newtab，不受影响。

### 5.5 popup 内容驱动高度（U5）

- `popup.html`：`body { width:360px; height:auto; max-height:600px; margin:0; overflow:hidden }`；`#root` flex column + `max-height:600px`。
- `popup/App.tsx`：根容器去 `h-full`；删除页脚提示条；删除「结果已在上方展开/展开 N 条结果」占位分支，body 恒显快捷动作 + 最近搜索 + 最近添加（结果下拉绝对定位覆盖）。
- 结果面板内快捷键提示保留为唯一一份。

### 5.6 键盘与无障碍（U6/U9，清偿 v2 遗留）

1. **TabStrip 方向键**（WAI-ARIA tabs 模式）：roving tabindex（active=0 其余 -1）；`←/→` 循环激活并聚焦、`Home/End` 首尾；Enter/Space 保留；拖拽重排不变。
2. **焦点陷阱**：新增 `src/ui/hooks/useFocusTrap.ts`（open 时记录 `document.activeElement`，Tab/Shift+Tab 在面板内循环，关闭还原焦点）；`Modal` 与 `Drawer` 接入。弹层栈 Esc 层级不变。
3. **`Alt+1..8` 切页签**：newtab 全局 keydown（与现有 Ctrl+K 同处），越界忽略；页签 title 追加提示。
4. **`?` 快捷键帮助**：非输入态按 `?` 开 `ShortcutsHelp` Modal（新组件），列出 Ctrl/⌘K、Ctrl+Shift+F、omnibox `bm`、↑↓/Enter/Ctrl+Enter/Esc、Alt+1..8、?；首页页脚追加「? 快捷键」提示。
5. 卡片网格方向键**不做**（记遗留）。

### 5.7 引导与响应式（U7/U8）

1. **推荐逻辑提取**：`store.ts:82-91` 的挑选逻辑提取为 `core/bookmarks.ts` 的 `pickRecommendedFolders(folders)`（纯函数：非 special、totalCount>0、优先 depth=1、slice 6）；store init 复用（先写表征测试再提取）。
2. **首跑 hint**：`seeded && !seedHintSeen && folderIds.length>0` 时问候行显示 chip「已按书签数推荐 N 个常用文件夹」+「调整」（开 picker）+「×」（写 `seedHintSeen:true`）。
3. **空态一键推荐**：EmptyState 主按钮「选择文件夹」旁增次按钮「一键选择常用文件夹」（调 helper 写 tabs + Toast）。
4. **FolderRail 双形态**：≥lg 维持 sticky rail；<lg 渲染水平 chips 行（同数据同跳转，overflow-x-auto，置于分区上方）。`max-h` 魔法数收敛为 FolderRail 导出常量 `RAIL_MAX_HEIGHT = 'calc(100vh - 108px)'`（新 header 84px + sticky top 8px + 底部余量 16px），rail/chips 共用一处定义。

### 5.8 操作反馈细节（U10）

1. **批量打开确认**：点击后 ConfirmDialog「在新标签页打开 N 个链接？」（N=min(10, items.length)，description 说明上限 10），确认后才循环打开；Toast 文案不变。
2. **卡片复制链接**：操作簇增 `Copy` 图标按钮（`navigator.clipboard.writeText` + Toast「链接已复制」/失败 danger Toast），stopPropagation 不触发打开；aria-label 完整。

## 6. 数据模型与兼容

`Settings.dashboard` 仅新增两个**可选**布尔（`settings.normalize` 浅合并天然兼容旧存档，缺省视为 false）：

```ts
seedHintSeen?: boolean;        // 首跑推荐 hint 是否已处理
controlsMovedSeen?: boolean;   // 设置迁移一次性 Toast 是否已提示
```

- `showStats` 语义不变（控制行内统计显隐），默认值不变 → 零迁移。
- 其余字段、存储划分、搜索排序恒定（书签 > 历史 > 网页）、删除链路（快照→回收站→确认）全部不变。
- 新增 core 纯函数 `pickRecommendedFolders` 遵守 core 无 DOM/React 约束。

## 7. 视觉与动效延续

- 「墨与鎏金」令牌、四强调色、亮暗双模、自绘滚动条、系统字体栈全部不变；抽屉/帮助 Modal 复用既有 `Drawer`/`Modal`/`panel-raised` 语言。
- 行内统计数字用等宽栈；健康度语义色沿用 ok/warn/faint。
- 入场阶梯与 hover 浮起保留；新增面板沿用 `rise-in`；`prefers-reduced-motion` 覆盖新增动画。
- 无音频（沿用技术方案 §7.4）。

## 8. 测试与验收

- 门禁沿用 agent.md：每阶段 `npm run typecheck && npm run test` 全绿才提交；行为变更先写复现失败测试（红→绿）；涉及主流程阶段加跑 `npm run build && npm run e2e`。
- 组件/单测重点：抽屉控件迁移后写盘语义（含防抖）、零查询面板三分支与 Esc 层级、popup 无占位分支、TabStrip 方向键 roving、焦点陷阱循环与还原、Alt+1..8、`pickRecommendedFolders` 表征、批量打开确认、复制链接成功/失败。
- E2E 新增断言（9 项，并入 `scripts/e2e.mjs`）：首卡 y≤200@1280×800；齿轮开抽屉且切布局即时生效；零查询聚焦出最近面板；popup body 高度 ≤600 且无死区（内容底边贴近容器底）；TabStrip ArrowRight 切换；焦点陷阱 Tab 循环；Alt+2 切页签；批量打开出确认框；800×600 chips 行可见可跳转。
- 视口矩阵：1280×800、1920×1080、1024×768 与 800×600（chips 形态）、popup 360×auto。
- 截图与文档同步：e2e 截图产出 `test-results/*.png` → 覆盖 `docs/screenshots/`；README 徽章用例数、功能文案同步（agent.md §5）。

## 9. 风险与回滚

| 风险 | 对策 |
|---|---|
| 老用户找不到设置 | 齿轮 title/aria + 一次性迁移 Toast（controlsMovedSeen） |
| 抽屉控件迁移遗漏写盘语义 | 迁移映射表逐控件对照 + 既有 DisplayControls 测试改写为抽屉测试，断言不放宽 |
| 零查询面板与结果面板 Esc/外点层级混乱 | 复用 popupStack 与现有 outside-mousedown；测试覆盖 Esc 三级层级 |
| popup 自适应在极端内容下超 600 | max-height + 中部滚动兜底；e2e 断言上限 |
| 首屏高度断言 flaky | 断言用 boundingBox 相对值 + 等待骨架消失；固定视口与字体栈 |

每阶段独立提交、可单独 `git revert`；阶段内不混行为变更与重构。
