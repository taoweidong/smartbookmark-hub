## S1 · 首页首屏重构 + 视图设置抽屉

**先写失败测试**：① 首屏结构断言（header 内不存在设置条 role/label、齿轮按钮存在）；② 抽屉内切布局/卡片/排序/每组/背景/主色/统计后 settings 写盘语义与现 DisplayControls 一致（改写既有 `DisplayControls.test.tsx` 为 `ViewSettingsDrawer.test.tsx`，断言不放宽）；③ 行内统计渲染与 `showStats` 显隐；④ 升级用户一次性迁移 Toast（旧存档 seeded=true 触发、新装不触发、只触发一次）。

**改动**：
- `src/pages/newtab/DisplayControls.tsx` → 重构为 `ViewSettingsDrawer.tsx`：外层 `Drawer`（title「视图设置」），内部分组「布局与卡片 / 背景与主色 / 显示 / 文件夹」，footer「重置视图」；防抖滑杆/取色器/换图逻辑原样保留。
- `src/pages/newtab/App.tsx`：header 去 `<DisplayControls>`；命令栏右簇加齿轮按钮（`SlidersHorizontal`，aria-label「视图设置」）；问候区单行化 + 行内统计三段（计算逻辑不变）；「数据仅存本机」chip 移页脚；抽屉 open state；迁移 Toast 条件（store.init 捕获 seeding 前 `seeded`，见方案 §5.2）。
- `src/core/store.ts`：init 内迁移 Toast 一次性逻辑（写 `controlsMovedSeen`）。
- `src/core/types.ts`：`dashboard.controlsMovedSeen?: boolean`。
- `src/ui/components/Feedback.tsx`：grep 确认 `StatTile` 无其他消费方后删除；行内统计 markup 落在 App（不新建组件）。
- 测试：`App.test.tsx`、`ViewSettingsDrawer.test.tsx`（原 DisplayControls 测试迁移）、`store.test.ts`。
- E2E（`scripts/e2e.mjs`）：+2 断言——1280×800 首张 `.bookmark-card` boundingBox.y ≤ 200（等骨架消失后测）；齿轮开抽屉切「列表」后卡片容器变单列且 settings 持久化。

**验收**：首卡 y≤200、首屏 ≥3 行卡片（1280×800 截图目视）；抽屉十控件写盘语义逐一对映射表；重置视图恢复默认；typecheck/test/build/e2e 全绿。
**回滚**：单 commit revert；settings 新字段可选，revert 后旧代码忽略之。

## S2 · 搜索零查询面板 + popup 自适应

**先写失败测试**：① `focus()` 空查询时面板开且含最近搜索/最近添加（hooks + components 测试）；② `change('')` 回零查询面板、`clear()` 关、Esc 层级（开→关→清→blur）不回归；③ 空查询时 Tab 不关面板（可 Tab 进入面板按钮）、有查询时 Tab 关面板不回归；④ popup 无「结果已在上方展开」占位、无页脚提示条；⑤ popup body 高度随内容（jsdom 断言结构：body 无固定 height style、根容器无 h-full）。

**改动**：
- `src/ui/hooks/useSearch.ts`：`focus()` 无条件 setOpen(true)；导出 `open` 去 query 相与；`change` 空值保持 open。
- `src/ui/components/SearchBox.tsx`：下拉三分支（有查询现状 / 零查询面板：最近搜索 chips ≤6 + 最近添加 ≤6 行 + 底部提示）；最近添加行复用 `result-row` 与 Favicon/timeAgo；`onFocus` 无条件 `setOpen(true)`（鼠标聚焦也出零查询面板）。
- `src/ui/hooks/useSearch.ts` 的 `onKeyDown`：Tab 分支改为「有查询才关面板」。
- `popup.html`：body `height:auto; max-height:600px`；`#root` flex column + max-height。
- `src/pages/popup/App.tsx`：根容器去 `h-full`；删页脚提示；删占位分支（body 恒显快捷动作/最近搜索/最近添加）。
- 测试：`hooks.test.tsx`、`components.test.tsx`、`popup/App.test.tsx`。
- E2E：+2 断言——newtab 聚焦空搜索出现最近添加面板（先搜一次产生 recentQueries 与最近添加数据路径）；popup 页 body `scrollHeight ≤ 600` 且结果少时容器底边与内容底边差 ≤ 24px（无死区）。

**验收**：三入口搜索语义不回归（Enter 冲刷防抖等既有测试全绿）；popup 360 宽高度自适应；提示仅一份。
**回滚**：单 commit；useSearch 导出语义变化仅 SearchBox/popup 消费，revert 同步还原。

## S3 · 键盘与 a11y

**先写失败测试**：① TabStrip ArrowRight/Left/Home/End 激活并聚焦、roving tabindex（active 0 其余 -1）；② 焦点陷阱：Modal/Drawer 内 Tab 循环不出面板、关闭还原打开前焦点（新 `useFocusTrap.test.tsx`）；③ Alt+2 激活第二页签、越界忽略、输入态不误触文案输入；④ `?` 非输入态开帮助、输入态不触发。

**改动**：
- `src/pages/newtab/TabStrip.tsx`：roving tabindex + 方向键 handler（激活即 `activate` + DOM focus）；title 追加「Alt+数字 切换」。
- 新增 `src/ui/hooks/useFocusTrap.ts` + 测试；`Modal.tsx`、`Drawer.tsx` 接入（替换现有首焦点逻辑，保留弹层栈 Esc）。
- 新增 `src/ui/components/ShortcutsHelp.tsx`（Modal 壳 + 快捷键表）+ 测试。
- `src/pages/newtab/App.tsx`：全局 keydown 增 Alt+1..8 与 `?`（非 input/textarea/select、无 ctrl/meta）；页脚加「? 快捷键」。
- E2E：+3 断言——TabStrip ArrowRight 切换 active；Modal 内连续 Tab 焦点仍在面板内；Alt+2 切页签。

**验收**：v2 遗留「完整焦点陷阱与 TabStrip 方向键导航」清偿；键盘全流程（聚焦搜索→结果→Esc→页签方向键→抽屉 Tab 循环）手测一遍录截图。
**回滚**：按主题两 commit（TabStrip+快捷键 / 焦点陷阱+帮助），可分别 revert。

## S4 · 引导与响应式

**先写表征测试再提取**：`store.test.ts` 现有 seeding 期望保持不变 → 提取 `pickRecommendedFolders(folders)` 到 `src/core/bookmarks.ts`（非 special、totalCount>0、优先 depth=1、slice 6）+ `bookmarks.test.ts` 直接覆盖（空集合、全 special、depth 混合、>6 截断）；store init 改调用 helper。

**先写失败测试**：① 首跑 hint 条件渲染（seeded && !seedHintSeen && 有文件夹）、「调整」开 picker、「×」写 seedHintSeen 后不再现；② 空态次按钮一键推荐写 tabs + Toast；③ <lg 视口 chips 行渲染且点击跳转分区、rail 隐藏；④ rail max-h 常量单一定义。

**改动**：`core/bookmarks.ts`、`core/store.ts`、`core/types.ts`（`seedHintSeen?: boolean`）、`newtab/App.tsx`（hint chip）、`newtab/Dashboard.tsx`（空态次按钮）、`newtab/FolderRail.tsx`（`variant: 'rail' | 'chips'` + 导出视口偏移常量）、测试同步。
**E2E**：+1 断言——800×600 视口 chips 行可见且点击后分区 scrollIntoView（active 高亮）。
**验收**：新装流程（demo 与真实 fresh profile）hint 出现一次；清空页签文件夹后空态一键恢复；1024×768/800×600 导航不缺失。
**回滚**：提取与 UI 两 commit；helper 为纯函数，revert UI 不回滚 helper 亦安全。
